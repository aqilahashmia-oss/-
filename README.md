# تطبيق شركة الوجية للسفر والسياحة

واجهة ويب بسيطة باللغة العربية تساعد على:
- عرض باقات السفر.
- إدخال بيانات الرحلة.
- حساب تكلفة تقديرية للحجز مباشرة في المتصفح.

## طريقة التشغيل (الأسهل)

### خيار 1: فتح الملف مباشرة
1. افتح ملف `index.html` بالنقر المزدوج.
2. سيعمل التطبيق مباشرة بدون تثبيت أي شيء.

### خيار 2: تشغيل سيرفر محلي (أفضل للتجربة)
```bash
python3 -m http.server 4173
```
ثم افتح الرابط:
`http://localhost:4173`

## ماذا لو لم يعمل؟
- تأكد أن الملفات الأربعة موجودة في نفس المجلد:
  - `index.html`
  - `styles.css`
  - `app.js`
  - `README.md`
- إذا شغّلت السيرفر المحلي، افتح الرابط الصحيح مع المنفذ `4173`.
- إذا ظهر خطأ في المتصفح، جرّب تحديث الصفحة (Ctrl+F5).

## ملاحظات
- هذا إصدار أولي (Front-end فقط) ولا يرسل بيانات إلى قاعدة بيانات.
- يمكن لاحقًا إضافة لوحة إدارة، حجوزات فعلية، ودفع إلكتروني.
